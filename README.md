# Information Network Security

This repository contains the practical programs and experiments performed for the **Information Network Security (INS)** subject in college.

## Topics Covered

- Caesar Cipher
- Monoalphabetic Cipher
- Rail Fence Cipher
  - Key-based Rail Fence Cipher
  - Custom Rail Fence Cipher
- Simple Columnar Transposition Cipher
- Vernam Cipher

## Programs

| File | Topic |
|---|---|
| `ceasarCipher.java` | Caesar Cipher |
| `monoalphabetics.java` | Monoalphabetic Cipher |
| `railFanceKey.java` | Rail Fence Cipher with Key |
| `railfanceCustom.java` | Custom Rail Fence Cipher |
| `simpleColumnar.java` | Simple Columnar Transposition Cipher |
| `vernamCipher.java` | Vernam Cipher |

## Purpose

This repository is created for **college practicals, cipher testing, and learning cryptography concepts**.
